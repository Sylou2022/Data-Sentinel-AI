
# Data-Sentinel-AI

De l'anomalie à la résolution : détecter, enquêter, expliquer, proposer, vérifier — en lecture seule.

## Lancer l'application

```bash
pip install -r requirements.txt
python -m api            # interface web et API : http://127.0.0.1:8000
```

- Interface web : `/` (Vue d'ensemble, Importer des données, Enquêtes, Rapports et exports, Journal d'audit, Paramètres).
- API REST : `/docs`.
- Docker : `docker compose up --build` puis http://localhost:8000.
